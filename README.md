# Fork demo, by 3d7 Technologies

An interactive demo of Fork, built by 3d7 Technologies: a tool that helps small employers and their teams make better pay, pension and benefits decisions.

**Open the demo:** https://3d7tech.github.io/fork-demo/

Use the strip at the top to switch between the **Owner view** and the **Employee view**, then pick a question to see the decision screen Fork builds for it.

All companies, people and figures are fictional and for illustration only. Fork gives guidance, not regulated financial or tax advice.
